### Flaky UI test, root cause found and fixed (PR #1245, issue #1244)

`ui/client/src/components/coach-chat/coachChatModel.test.ts` failed a different test on most local
runs with `Test timed out in 5000ms`. Cause: tests that fail a fetch on purpose waited through the
real `fetchWithRetry` backoff (500ms then 1s). The file took 16.5s, and a test with two failing
calls sleeps 3s, so under load it crossed vitest's 5s limit. Test-only fix: backoff sleeps run at
once, the 5s proactive-snapshot abort timer is left alone. The file now runs in about 50ms and passed
5 of 5 runs.

could not be exercised in run 4, because that run never completed.

model's own notes.
